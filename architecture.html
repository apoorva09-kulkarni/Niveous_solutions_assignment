Why each design choice

ChoiceReason
One agent with four toolsEach step is easy to explain and check. Several shallow agents would be harder to defend.
Human approvesRBI keeps the bank accountable for lending decisions, so the agent only recommends.
Calculations are real, AI reasoning is simulatedThe numbers can be checked by hand. We do not claim a live AI model is running.
BigQuery as targetIt can hold tables, documents and API results in one platform. It is not connected in this demo.

The layout follows the common agent-plus-data-platform pattern: enterprise data flows through ingestion into a data platform, tools expose that data to an agent, and an application serves the user, with a human-in-the-loop step. Parts of that pattern, such as agent-to-agent communication and learning from officer feedback, are future work and not built here.
